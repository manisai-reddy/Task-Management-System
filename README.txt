# TaskFlow - Task Management System

## VS Code
1. Extract this ZIP.
2. Open the `TaskFlow_VSCode` folder in Visual Studio Code.
3. Open `index.html`.
4. Run it with Live Server, or open `index.html` directly in a browser.
